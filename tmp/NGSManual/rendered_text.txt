1. 시스템 개요 
1.1 설비 목적 
불량선별기는 선별트레이(Source)에 있는 NG 셀을 한 개씩 취출하여 대상트레이(Target)의 빈 채널에 삽입합
니다. FMS에서 수신한 트레이·셀 정보를 기준으로 작업하며, 실제 이재 결과와 출발·도착 채널을 저장하고 
FMS에 보고합니다. 
• Source와 Target는 각각 최대 96채널이며 4열 × 24셀로 구성됩니다. 
• X/Y/Z 서보 3축으로 위치를 제어하고, 실린더형 그리퍼로 셀을 CHUCK/UNCHUCK합니다. 
• PLC는 트레이 투입·배출·센터링을 담당하며, PC는 선별 및 FMS 연계를 수행합니다. 
• 대상트레이 만셀 시 교환 후 동일 Source의 남은 작업을 계속할 수 있습니다. 
• Pause, 수동 작업 완료, 조건부 비상정지 복구는 서로 다른 절차입니다.

2.1 기본 안전 수칙 
• 자동 운전 중 도어를 열거나 셀·그리퍼·트레이·이송부에 손을 넣지 않습니다. 
• Pause, STOP MOVING, 알람창 닫기는 비상정지 또는 에너지 차단을 대신하지 않습니다. 
• 내부 작업 전 실제 전 축 정지와 현장 안전 절차를 확인합니다. BYPASS는 정비용 승인 절차에서만 사용합
니다. 
• 셀을 보유한 상태에서 임의로 그리퍼를 열거나 트레이를 교체하지 않습니다. 
• 센서 강제 입력, PLC/FMS 값 강제 쓰기, Cycle/Dry Run/Maximum speed로 생산 인터락을 우회하지 않습니
다. 
• 눌림·끼임·충돌 위험 또는 예상하지 못한 동작이 있으면 비상정지하고 원인을 확인합니다.

3.3 96채널 선별 화면 
두 트레이의 채널 표시를 함께 보면서 출발 셀과 도착 슬롯을 확인합니다. 채널 번호는 4열 × 24셀의 논리 
번호이며, 현물 방향과 티칭 좌표를 임의로 바꾸지 않습니다. 
표시 대상 의미 작업자 확인 
Source NG 선별 대상 셀 CellExist, Grade=NG, 선별 상태 및 Cell ID 확인 
Source 취출 완료 이미 꺼낸 셀의 완료 기록 셀을 원위치에 돌려놓았다면 자동 재개 전에 기록 일치 확인 
Target 빈 채널 삽입할 수 있는 위치 다른 셀이나 그리퍼 예약과 충돌하지 않는지 확인 
Target 예약 채널 현재 이재 작업에 할당된 위치 작업 완료로 단정하지 않음. 수동 삽입 시 실제 채널 확인 
Target 삽입 완료 삽입 기록이 확정된 셀 Cell ID 및 셀 보고/저장 완료 여부 확인 
남은 NG 없음 해당 Source 선별 종료 대상 ProcessEnd와 Source Tray Out 완료까지 대기 
 
일반 선별 대상 선택은 Source의 셀 존재, NG 등급, PICK 상태와 불량 코드 조건을 함께 사용합니다. 화면 
색상만으로 선별 완료 또는 FMS 보고 완료를 판단하지 않습니다. 
동일 Tray ID 시험 시 주의 
같은 Tray ID를 반복 사용하면 FMS 정보와 로컬 완료 기록이 충돌할 수 있습니다. 이전에 취출한 셀을 다시 
적재하거나 빈 트레이를 재사용한 경우 실제 상태와 저장 기록을 검증해야 합니다. RESET WORK로 무조건 
해결된다고 가정하지 않습니다. 
수동으로 셀을 이동한 뒤 그리퍼가 비어 있다는 이유만으로 완료로 처리하지 않습니다. Source/Target 채널
과 Cell ID를 확정하는 수동 작업 완료 절차가 필요합니다.

4. 기동 및 종료 
4.1 프로그램 기동 
1. 현장 전원 투입 절차에 따라 PC, PLC, 안전회로, 서보 및 주변 장치 상태를 확인합니다. 
2. NGSORTER와 OPC UA Gateway를 실행하고 NGSORTER 장비 설정이 선택되어 있는지 확인합니다.

4. 도어 닫힘, KEYLOCK 설정, BYPASS 생산 위치, 비상정지 해제를 확인합니다. 필요 시 SAFETY RESET 후

5. Servo OPEN을 실행하고 시스템 시작 상태와 알람을 확인합니다. 이후 Servo ON, HOME 순으로 준비합니
다. 
6. HOME과 전 축 정지, 그리퍼 및 트레이 상태를 확인합니다. 일반 운전은 그리퍼 열림·셀 없음이 필요합니
다. 
7. 프로그램 AUTO를 선택하고 START를 실행합니다. 두 트레이의 ID 및 FMS 정보를 확인한 뒤 자동 진행을 
감시합니다. 
4.2 정상 종료 
1. 진행 중인 셀 이재와 FMS 보고를 완료하고, 그리퍼의 셀 보유 여부를 확인합니다. 
2. 현장 절차에 따라 트레이를 처리하고 안전한 대기 상태로 만듭니다. 
3. MANUAL로 전환하여 전 축 정지를 확인합니다. 미완료 수동 완료 보고 또는 FMS 대기가 없는지 확인합
니다. 
4. 결과·로그 저장 완료 후 프로그램을 정상 종료합니다. 종료 시 설비 Power/환경 Running 상태 보고가 시
도됩니다. 
5. 필요 시 Windows 및 설비 전원을 현장 종료 순서에 따라 차단합니다. 
통신이 끊어진 상태의 종료 보고는 FMS 도달을 보장하지 않습니다. 셀을 잡았거나 보고 결과가 불명확한 
상태에서 프로그램을 강제 종료하지 않습니다.

2. 축 주변 간섭·셀 보유·트레이 위치를 확인하고 낮은 JOG 속도를 선택합니다. 
3. 축 방향 버튼을 누르는 동안 이동시키고 놓아서 정지합니다. 화면 위치값과 실제 이동을 확인합니다. 
4. Z축 상승/하강 버튼은 JOG 패널 아래에 있습니다. 하강은 선택 채널과 티칭 위치를 확인한 후 사용합니
다. 
5. 동작이 끝나지 않거나 시퀀스 대기가 지속되면 STOP MOVING을 사용하고 정지 확인 상태를 확인합니다. 
항목 현재 동작 
JOG 속도 수동 축 조작 속도. 실제 이동량과 단위는 검증된 기어비·기구 설정에 따름

Target Z 하강 티칭된 저속 시작 Z 높이까지 이동 후 최종 하강 구간을 별도 속도로 이동 
Jog/Z 속도 저장 설정창에서 적용·저장 후 다음 기동 시 저장값 사용 
 
이전 80%/20% 명칭이 있더라도 현재 Target는 티칭된 저속 시작 높이를 기준으로 사용합니다. 빠른 구간 
끝이 셀·트레이 접촉 구간에 들어가지 않도록 담당자가 검증합니다. 
6.3 티칭값 저장 
Source/Target 채널별 기준 X/Y와 Z 하강 위치, Standby Position을 확인합니다. 96채널 위치는 기준 티칭값

3. Manual work complete에서 Source Tray/채널, Target Tray, Cell ID를 확인합니다. 
4. 실제로 삽입한 Target 채널 번호를 입력합니다. 다른 셀이 있는 채널을 덮어쓰지 않습니다.

7.3 Door Keylock Bypass 절차 
다음은 현재 프로그램의 정상 정지 상태에서 사용하는 조작 순서입니다. 설비 내부 진입 허가는 별도의 현
장 안전 기준을 따릅니다. BYPASS 상태를 유지한 자동 생산은 허용하지 않습니다. 
순서 도어 열기 확인 
1 Pause 후 MANUAL 전환 전 축 정지 확인 
2 작업자가 BYPASS 키 ON 전환 X002A=ON, X0029=OFF 
3 Release KEYLOCK 클릭 프로그램이 Y003C OFF, Y003D ON 요청 
4 프로그램 지연 처리 대기 500ms 후 Y0033/Y0034 OFF, 해제 조건 재검사 
5 해제 상태 확인 후 도어 열기 도어/키락 상태와 실제 정지 확인 
 
순서 도어 닫기 확인 
1 작업자가 두 도어 닫기 프로그램 기준 X0026/X0027 모두 OFF 
2 Set KEYLOCK 클릭 Y0033/Y0034 ON 
3 프로그램 완료 대기 500ms 후 Y003D OFF 및 키락 설정 완료 확인 
4 Set BYPASS 클릭 
Y003C ON: BYPASS 키를 OFF로 돌릴 수 있도록 잠금 해
제 
5 작업자가 BYPASS 키 OFF 전환 X0029=ON, X002A=OFF 
6 안전·작업 상태 확인 후 AUTO → START/Restart 미완료 셀 처리나 보고가 있으면 먼저 복구 
 
Y003C와 Y003D를 구분합니다. 
현재 코드에서 Y003C는 BYPASS 키의 기계적 잠금 해제 출력이며, Y003D는 Safety Bypass 출력입니다. Set 
BYPASS 버튼은 Y003C를 제어합니다. 예전의 “SOL 해제” 명칭만으로 출력을 판단하지 마십시오. 
X0026/X0027은 프로그램에서 ON=도어 열림/키락 해제, OFF=닫힘/키락 설정으로 해석합니다. 전원 단절 시 
OFF만 보고 실제 도어 닫힘을 단정하지 않습니다.

7.4 Emergency 복구 및 작업 계속 
1. 비상정지 후 실제 축 정지, 셀 보유 상태와 트레이 위치를 확인합니다. 프로그램은 Pause/수동 복구 상태
로 전환됩니다. 
2. 원인을 제거하고 사람·공구가 동작 영역 밖에 있는지 확인합니다. 실제 셀을 옮겼다면 기록 정합성을 먼
저 처리합니다. 
3. 비상정지를 해제하고 도어 닫기 → Set KEYLOCK 완료 → Set BYPASS → BYPASS 키 OFF 순으로 안전 상
태를 복구합니다. 
4. SAFETY RESET 후 X002B와 X002C가 모두 ON인지 확인합니다. 안전회로가 성립하지 않으면 이후 진행을 
중지합니다. 
5. Servo OPEN, ON, HOME을 실행하고 전 축 정지와 알람 상태를 확인합니다. 보유 셀을 임의로 UNCHUCK
하지 않습니다. 
6. 복구 정보가 유효하고 필요한 조건이 모두 맞으면 AUTO를 선택한 뒤 START/Restart를 누릅니다. AUTO 
선택만으로 자동 이동하지 않습니다. 
옵션/실제 상태 재개 방식 
비상정지 자동 재시작 OFF 기존 일반 AUTO 조건 적용. 셀 보유 상태의 자동 진입 불가 
옵션 ON, 취출 전·빈 그리퍼 유효한 복구 기록 확인 후 해당 Source 채널부터 취출 
옵션 ON, CHUCK·셀 보유 확인 Source 완료 상태 확인 후 Target 이동·삽입부터 재개 
옵션 ON, Target 해제 확인 중복 삽입 없이 저장·CellTrackOut 보고 단계부터 복구 
센서·셀·Tray ID 불일치 자동 재개 금지. 실제 상태와 보고 기록을 수동 복구 
프로그램 종료/트레이 제거 기존 EMG 복구 기록을 그대로 사용할 수 없음 
 
복구 옵션은 무조건 자동 재시작 기능이 아닙니다. 같은 트레이·셀 기록, HOME, 안전, 정지, 센터링 및 FMS 
조건이 모두 검증되어야 합니다. 그리퍼에서 셀을 제거한 것만으로 이재 완료가 되지 않습니다.

9.3 FMS 설비 상태 및 알람 
태그 값 또는 규칙 
EquipmentStatus.Power false: OFF / true: ON 
EquipmentStatus.Mode 1: Manual / 2: Control 
EquipmentStatus.Status 1: Idle / 2: Running / 4: Machine Trouble / 8: Pause 
Trouble.ErrorNo 현재 유효한 오류 코드 배열 
Trouble.ErrorLevel 현재 배열의 첫 번째 전체 오류 코드. 오류 없음은 0 
알람 분류 10: System / 20: Servo / 30: Operation / 40: System Error / 50: 기타 설비 오류 
 
원래 서보 코드와 축·상세번호는 Servo Alarm 화면에서 확인합니다. FMS 코드만으로 모든 원인을 확정하지 
않습니다. 예: Servo 1Ah는 20026으로 보고됩니다. 오류가 해제되어도 자동 재시작하지 않으며, 실제 상태에 
맞는 Restart가 필요합니다.

보전 담당자에게 전달하십시오.
