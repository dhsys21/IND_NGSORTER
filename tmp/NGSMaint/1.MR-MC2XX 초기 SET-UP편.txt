16
PB Test Setting – 파라미터 셋팅
새로 만들기 시스템 리부트 파라미터 초기화 파라미터 셋팅 시스템 기동
※ Parameter 변경에는 아래 2가지 방법이 있습니다.
1. Change Parameter Write
각각의 파라미터를 Host PC에서 포지션 보드 MR-MC2XX로 전송합니다.
① 장 점
- 필요한 파라미터만 변경이 가능합니다.
- PB-TEST TOOL을 사용하지 않고 API 함수만으로 파라미터 변경이 가능합니다.
- Host PC 또는 포지션 보드가 고장나도 프로그램 내에 기입이 되어 있기 때문에
별도의 관리가 불필요 합니다.
② 단 점
- 변경 파라미터 수량 만큼 API 함수를 작성 하셔야 합니다.
- 변경한 파라미터의 수량이 많은 경우 시스템 기동까지의 시간이 오래 걸립니다.
2. Flash ROM 파라미터 백업 및 LOAD
포지션보드 MR-MC2XX에 내장된 Flash ROM에 파라미터를 저장하고 시스템 기동 이전에
파라미터를 불러와 사용하는 기능입니다.
① 장 점
- 파라미터 변경이 쉽고 간편 합니다.
- 시스템 기동까지의 시간을 최소화 합니다.
- Host PC가 고장이 날 경우에도 DATA가 포지션 보드 Flash ROM에 보존됩니다.
② 단 점
- PB-TEST TOOL의 사용방법을 숙지하셔야 합니다.
- 포지션 보드가 고장날 경우를 대비하여 PB-TEST의 PJT파일로 백업해놔야 합니다.
