1. 안전 및 작업 준비 
본 매뉴얼은 정상 설정의 확인과 승인된 복구 작업을 위한 문서입니다. 안전회로를 우회하여 움직임을 만드
는 절차는 다루지 않습니다. 전기 배선, 보드 탈착 및 모터·센서 교체는 자격을 갖춘 담당자가 수행합니다. 
작업 시작 전 
1. 자동 운전을 종료하거나 Pause 후 MANUAL로 전환하고 실제 전 축 정지를 확인합니다. 
2. 그리퍼에 셀이 있는지, Source/Target의 실제 적재 상태와 미완료 FMS 보고가 있는지 기록합니다. 
3. 기계 내부·전장 작업은 현장 LOTO 절차로 전기·공압 등 위험 에너지를 차단합니다. Z축과 보유 셀의 낙하 
위험을 별도로 방지합니다. 
4. 서보 앰프의 잔류 전압이 해소되었음을 제조사 절차로 확인한 후 커넥터·보드를 취급합니다. 
5. 변경 전 프로그램, 설정, 티칭, 보드 파라미터 및 로그를 백업합니다. 한 번에 한 항목씩 변경하고 결과를 
기록합니다. 
금지 사항 
• BYPASS, CC-Link 출력 강제 쓰기, 센서 단락으로 안전 조건을 만들어 시운전하지 않습니다. 
• Pause와 STOP MOVING은 에너지 차단이 아닙니다. 화면이 사라지거나 버튼 색이 바뀐 것만으로 안전 진
입을 판단하지 않습니다. 
• PB Test와 NGSORTER에서 같은 보드로 동시에 동작 명령을 내리지 않습니다. 
• 출처가 다른 서보 프로젝트를 Write All하거나 파라미터 전체 초기화하지 않습니다. 
• 셀·공구가 놓인 상태에서 HOME이나 저속 시험을 시작하지 않습니다. 저속도 충돌을 방지하는 안전기능은 
아닙니다.

3.1 PB Test 설치와 Board Open 
1. NGSORTER 및 보드를 사용하는 프로그램을 종료합니다. 승인된 MRZJW3-MC2-UTL Ver.3.10 패키지를 준
비합니다. 
2. LaunchUtl.exe에서 MC2xx 설치를 진행합니다. MR-MC240은 MC2xx 대상이며 MC3xx로 대신 설치하지 않
습니다. 
3. 드라이버 설치와 재부팅 후 Position Board Test Tool을 실행합니다. 장치 드라이버 로드 오류가 있으면 동
작 시험을 중지합니다. 
4. Project Setting에서 MR-MC240, Board ID 0, Channel 1, Interface BUS를 확인합니다. 
5. 처음은 Monitor mode로 읽기·상태 확인을 수행합니다. 기동 시험이 필요할 때만 안전 확보 후 Test mode
를 사용합니다. 
6. Open Connection 후 상태 표시와 System alarm을 확인합니다. Ready fin만으로 모터 전원·Servo 
ON·HOME 완료를 판단하지 않습니다. 
 
그림 3-1. Project Setting: 모델, Interface, Board ID 및 Channel 
PC 내부 MR-MC240 보드의 Interface는 BUS를 사용합니다.

3.2 프로젝트와 3축 구성 
8월 13일 백업은 Axis1=X, Axis2=Y, Axis3=Z의 독립 3축입니다. 축 사용 여부는 System의 총 축수 항목이 아
니라 Parameter Data → SampleData.prm2 → Control에서 축별로 확인합니다. 
Control 항목 Axis1 X Axis2 Y Axis3 Z 
0200 OPC1 0001h 0001h 0001h 
0203 AXALC 0001h 0002h 0003h 
0264 TGRP 0000h 0000h 0000h 
0265 TOP 0000h 0000h 0000h 
 
1. 백업 폴더의 IND_NGSORTER_SERVO.pbp2를 작업용 사본으로 열고, Parameter Data의 SampleData.prm2를 
엽니다. Point Data(.pnt2)와 구분합니다. 
2. Control 0200 OPC1의 사용 축 설정을 확인합니다. 이 백업의 Axis1~3은 0001h, Axis4~32는 0000h(미사용)
입니다. 다른 옵션이 섞인 프로젝트에는 이 전체 Word 값을 무조건 덮어쓰지 않습니다. 
3. 0203 AXALC 값 0001h/0002h/0003h와 앰프 실물 축 번호를 대조합니다. 스위치 0/1/2 및 앰프 표시 
n01/n02/n03의 대응을 확인합니다. 
4. 0264 TGRP와 0265 TOP이 세 축 모두 0000h인지 확인합니다. 승인 설정을 적용한 뒤 Positioning Test의 
Axis 목록에 Axis1, Axis2, Axis3가 각각 표시되는지 확인합니다. 
 
그림 3-2. 독립된 Axis1, Axis2, Axis3 선택 
백업의 System 0002 SYSOP2는 0000h로 축번호 자동 할당 상태입니다. 0203 값을 기록했다고 수동 할당 모
드가 활성화된 것은 아닙니다. 이 구성에서는 앰프 번호와 보드 축의 기본 대응도 함께 확인하며, SYSOP2를 
임의 변경하지 않습니다.

3.3 System startup과 파라미터 저장 
 
그림 3-3. Positioning Test에서 Parameter 선택 후 System startup 
1. 기존 보드값을 읽어 백업하고, Positioning Test의 Parameter에 승인된 SampleData.prm2를 선택합니다. 
Edit로 축·센서·전자기어·원점값을 확인합니다. 
2. Do not send servo parameters는 앰프 파라미터 전송 여부입니다. 복구 범위와 제조사 적용 조건에 맞게 
사용하며, 이름만 보고 임의 선택하지 않습니다. 
3. 기계 정지 및 안전 확보 후 System startup을 실행합니다. 적용값을 읽어 확인하고 축 목록과 알람, Ready
를 확인합니다. 
4. PC의 .prm2 저장과 보드 Flash ROM 보존은 별개입니다. 승인된 백업 절차에 따라 각각 확인하고, 변경 
후 HOME·방향·정량 이동을 재검증합니다. 
운영 프로그램 OPEN과 파일 적용 
운영 프로그램의 신규 서보 기동은 D:\IND_NGSORTER_SERVO\SampleData.prm2를 읽습니다. System과 
Axis1~3 값을 검증·적용하고 System start를 실행하며, 이 경로는 Flash ROM을 변경하지 않습니다. 
이미 보드가 RUNNING이면 기존 시스템을 재사용하여 재기동과 파일 재적용을 생략합니다. 따라서 파일만 
수정한 뒤 OPEN을 누르거나 프로그램만 다시 실행했다고 새 값이 적용된 것으로 판단하면 안 됩니다. 승인
된 정지·재기동 절차 후 실제 보드값을 읽어 확인합니다. 
백업은 날짜별 폴더에 보관하고, 검증을 완료한 파일을 운영용 D:\IND_NGSORTER_SERVO 폴더에 배포합
니다. 변경·배포·복원 파일을 혼동하지 않습니다.

맞는다고 확정하지 않습니다.

6.1 TSD V50 설치와 현장 설정 
TSD-V50은 DC 24 V 계통과 RS-485 통신을 사용하는 온도·연기감지기입니다. 센서 위치, 흡입부 오염, 기류

확인 항목 설정 또는 작업 기준 
전원 / 결선

지 않음

통신 규격 RS-485, 115200 bps, 8 bit, None parity, 1 stop bit 
PA1 / PA2 온도 경고 / 위험 설정. 승인된 기준값 사용 
PA3 온도 오프셋. 교정 근거 없이 표시값을 맞추기 위해 변경하지 않음 
PA4 
Human Automation 또는 Modbus RTU 통신 모드. 장치 표시와 프로그램의 모드명을

본체 파라미터 변경 
1. MODE와 UP/DOWN으로 설정 화면 및 파라미터 번호를 선택합니다.

3. SET을 3초 이상 눌러 저장하고 3회 점멸을 확인합니다.

Automation / Modbus RTU 명칭으로 맞춥니다.

8.1 PLC 전력 정보 수신 
현재 NGSORTER에는 직접 연결하는 파워미터가 없으며 PLC에서 전력 정보를 받습니다. PC는

값 PLC 주소 변환 단위 
Voltage D10110 / D10111 UInt32 ÷ 1000 V 
Current D10112 / D10113 UInt32 ÷ 1000 A 
Power D10114 / D10115 UInt32 ÷ 1000 kW 
Energy D10116 / D10117 UInt32 ÷ 1000 kWh

8.2 전력 계측 계통 점검 
PLC 측 전력 계측 계통은 전장 도면과 승인 설정에 따라 점검합니다. 계측기 → PLC → PC → FMS 순서로

설치와 셋업 확인 순서 
1. 계측 위치, 장치 형명·정격, 전압·전류 범위 및 단상/삼상 결선 방식을 확인합니다.

화면과 사진은 조작 위치 및 점검 대상을 식별하기 위한 자료입니다. 화면의 숫자·출력 상태·시험 데이터는

구분 확인사항 
설치·프로그램 화면 
Position Board, 시리얼카드 및 BCR 설치 화면은 운영 PC의 설정 이력입니다. 
Teaching·Configuration·Interface·Jog/Z 등 프로그램 화면에는 설명용 화면이 포함되어 있으며, 
노트북 표시값과 운영 PC 설정은 다를 수 있습니다. 표시된 좌표·IP·온도·알람·시험 코드를 승
인 운영값으로 복사하지 않습니다. 
CC-Link Master 화면 
그림 4-1은 국번호 1의 Standby master station 화면입니다. 운영 Master 설정 완료 상태를 
나타내지 않으며, 실제 Master는 4.1절에 따라 국번호 0으로 확인합니다. 
CC-Link 오류 및 I/O 화면 
그림 4-3은 링크 오류 진단 화면입니다. 그림 4-4는 2026.08.06 상태 기록이며 Y 출력 조합

02 및 최신 I/O 도면을 적용합니다. 
시리얼 설치 화면 
설치 화면의 드라이버 선택 이력은 다른 PC·시리얼 카드에 동일 드라이버를 적용하라는 의미
가 아닙니다. 화면에 포함된 호환성 경고는 해당 하드웨어 ID와 제조사 지원 조건으로 판정
합니다. 
Z 속도 표시 명칭 
Z first 80% speed / Z final 20% speed는 고속·저속 설정의 화면 명칭입니다. 실제 전환 기준
은 Target의 절대 Z 감속 시작 위치이며, 이동거리 비율 분할로 해석하지 않습니다. 
자료 및 검증 범위 
설치 자료, 운영 화면 및 프로그램 동작을 기준으로 정리했습니다. 서보 HOME 항목은 MR-
MC200/300 IB-0300223 Control Parameters, 직렬 장치 식별은 Intel AMT SOL 자료와 함께 
검토한 내용입니다. 현장 결선·안전회로·설치 파라미터의 최종 승인 기록 및 실제 동작·안전기
능 시험을 대체하지 않습니다.
